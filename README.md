# fressay-netsuper-cart

> **非公式です。株式会社フレッセイとは関係ありません。** 個人が作った AI 用の skill で、運営会社に確認を取ったものではありません。

> **AI を使い慣れた人向けです。** 入れるには、ブラウザを操作できる AI（下の「必要なもの」）と、skill のアップロードが要ります。AI をふだん使わない人が、そのまま使える形ではありません。

フレッセイネットスーパーで、「牛乳、食パン、卵」のような文章の買い物リストを渡すと、AI があなたのブラウザを操作してカートに入れ、一覧を見せて止まる skill です。**注文の確定はしません**。支払いと注文は、一覧を見てからあなたが行います。

## できること

- 文章の買い物リストをカートに入れる（「牛乳、食パン、卵を入れて」）
- お気に入りの品をまとめてカートに入れる（「お気に入りを全部入れて」）
- 前回の注文と同じ品を探して入れる（「前回と同じものを入れて」）
- カートの数量変更・削除（「牛乳を 1 本に減らして」）

迷う品（容量違い・メーカー違い・別の商品が混ざるもの）は勝手に入れず、最後に候補を番号付きで出します。すでにカートにある品は入れ直しません（入れ直すと数が足されるため）。

## しないこと

- 「お会計へ」から先へ進むこと（支払い・注文の確定）
- ID・パスワードの入力（ログインはあなたが行います）
- 当日／翌日や配達の便を選ぶこと（あなたがサイトで選びます）
- 配達先・会員情報の変更

## 必要なもの

- フレッセイネットスーパーの会員登録
- ブラウザを操作できる AI のどれか
  - Claude: Claude in Chrome（Chrome 拡張・有料プラン）、Claude デスクトップの Cowork、Claude Code のいずれか
  - ChatGPT: ブラウザで操作できるモード（ChatGPT デスクトップアプリ）。skill を入れるには、サイドバーの「プラグイン」に「スキル」のタブが出るプランが要ります（Plus で出ることを 2026-11-04 に確認。ほかのプランは未確認）

## 入れ方

### 1. ZIP を作る

このリポジトリの `skills/fressay-netsuper-cart` フォルダを ZIP にします。**ZIP を開いたとき、いちばん上に `fressay-netsuper-cart` フォルダがあり、その中に `SKILL.md` がある形**にしてください。

- GitHub の「Code」→「Download ZIP」でリポジトリごと落とし、展開してから `skills/fressay-netsuper-cart` フォルダを右クリックして ZIP にする
  - Windows: 右クリック →「送る」→「圧縮 (zip 形式) フォルダー」（Windows 11 は「ZIP ファイルに圧縮する」）
  - Mac: 右クリック →「"fressay-netsuper-cart" を圧縮」

### 2. AI に入れる

**Claude**

1. claude.ai の設定 >「機能」で、「クラウドでコードを実行」を有効にする（skill を使う前提）
2. 設定 >「カスタマイズ」>「Skills」を開き、右上の「追加」→「Skills をアップロード」で ZIP を選ぶ（名前は日本語表示で 2026-11-04 に画面を確認。ZIP のアップロード自体は試していません）
3. Chrome 拡張（Claude in Chrome）・Cowork・Claude Code から使えるようになります

Claude Code だけで使う場合は、`skills/fressay-netsuper-cart` フォルダを Claude Code の skill フォルダ（例: `~/.claude/skills/`）に置いても使えます。

**ChatGPT（「スキル」のタブが出るプラン）**

1. サイドバーの「プラグイン」を開き、「スキル」タブ →「追加」→「コンピューターからアップロード」で ZIP を選ぶ（名前は日本語表示の Plus プランで 2026-11-04 に画面を確認。ZIP のアップロード自体は試していません）
2. アップロード後に ChatGPT 側で内容の検査があります

**ChatGPT（「スキル」のタブが出ないプラン）**

skill としては入れられません。`SKILL.md` の本文をコピーして、ブラウザで操作できるモードの ChatGPT に貼り付けてから、買い物リストを伝えてください。**この使い方は、まだ試していません。**

## 使い方

1. ブラウザでフレッセイネットスーパーにログインする
2. サイトの画面で、当日お届けか翌日お届けかと配達の便を選び、入店する
3. AI に頼む: 「フレッセイのネットスーパーで、牛乳、食パン、卵をカートに入れて」
4. Claude in Chrome を使う場合、最初にサイトへのアクセスの許可を求められます。「fressay-netsuper.axial-r.com での操作をすべて許可」を選ぶと、そのセッションの間は聞かれなくなります（毎回聞かれたくなければ、拡張の設定でこのサイトを許可しておきます）
5. AI がカートの一覧を出します。迷った品は番号で選んでください
6. 一覧を確かめてから、サイトの「お会計へ」から自分で注文する

**いつも買う品は、サイトのお気に入りに入れておくのがおすすめです。** お気に入りにある品は、AI が迷わず決められます。

## 気をつけること

- 注文は商品合計（税抜）1,200 円からです。届かないときは、AI があといくら足りないかを伝えます
- 会員規約では、同じ商品を 5 個以上注文するときは配送希望日の 3 日前までに担当店舗への連絡が必要です
- 会員規約では、ID とパスワードを本人以外（家族を含む）に貸すことはできません。自分のアカウントで使ってください
- 規約を守る責任は使う人にあります。サイトの運営に悪影響があると判断された場合、利用停止になることがあると規約に書かれています。AI には 1 品ずつ、普通の速さで操作させてください
- サイトの画面が変わると動かなくなることがあります

## 原信ネットスーパーについて

同じ仕組みの原信ネットスーパーでも動く可能性があります（AI に「ベース URL は `https://harashin-net.axial-r.com/super`」と伝える）。ただし試していません。原信の会員規約も自分で確かめてから使ってください。
